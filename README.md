# بساط ناب (Basate Nab) - WordPress WooCommerce Vintage Theme

فروشگاه اینترنتی تخصصی **بساط ناب** ([https://basate-nab.com/](https://basate-nab.com/)) - مرجع عرضه انواع آباژورهای وینتیج، چراغ‌های رومیزی و کنارسالنی، تابلوهای رترو، ظروف کهنه‌کاری و اشیای آنتیک با هارمونی اختصاصی پیج اینستاگرام [@basate_nab](https://www.instagram.com/basate_nab) و الگوبرداری از ساختار مدرن UX فروشگاهی noor3tar.

---

## ۱. ویژگی‌های کلیدی پوسته (Key Features)

* **طراحی رترو و وینتیج اختصاصی (Vintage & Retro Aesthetic):**
  * هارمونی رنگی الهام‌گرفته از عتیقه‌جات و تم پیج اینستاگرام (`#B8860B` برنجی کهنه‌کاری، چوب گردوی تیره `#231709` و پارچمنت کرم `#FBF9F4`).
  * تایپوگرافی تمیز و خوانا با فونت رسمی **وزیرمتن (Vazirmatn)**.
* **ناوبری موبایل اپلیکیشنی (Mobile Bottom App Bar):**
  * نوار پایین چسبان موبایل با دسترسی سریع به خانه، دسته‌ها، سبد خرید با شمارنده زنده، حساب کاربری و اینستاگرام.
* **استوری دسته‌بندی‌ها (Category Stories):**
  * آیکون‌های گرد افقی مشابه noor3tar برای پیمایش سریع در دسته‌های آباژور رومیزی، آباژور سالنی، تابلوهای رترو، ظروف آنتیک، گرامافون و رادیو.
* **یکپارچگی کامل با ووکامرس (WooCommerce Integration):**
  * پشتیبانی از واحد پولی تومان (IRT)، ارقام فارسی (`۰۱۲۳۴۵۶۷۸۹`) و به‌روزرسانی لحظه‌ای سبد خرید (AJAX Cart Fragments).
  * کارت‌های کالا با درصد تخفیف، قیمت قبل و بعد، وضعیت موجودی و دکمه افزودن سریع.
* **موتور سئوی پیشرفته (Advanced Technical SEO Engine):**
  * ساختار داده‌های نشاندار JSON-LD: اسکیماهای `WebSite` با جستجوی سایت، `Organization` و `HomeGoodsStore` با لینک به اینستاگرام، `Product` با قیمت به تومان، وضعیت موجودی و `BreadcrumbList`.
  * تگ‌های کامل Open Graph و کارت‌های توییتر (Twitter Cards).
  * ساختار پیوندهای یکتا استاندارد (`/%postname%/`).
* **شمارنده پیشنهاد ویژه (Special Offer Countdown):**
  * تایمر معکوس تخفیف عتیقه‌جات با انیمیشن و اعداد فارسی.
* **بخش شبکه‌های اجتماعی و ویترین اینستاگرام:**
  * لینک مستقیم به [@basate_nab](https://www.instagram.com/basate_nab) با گالری ۶ تایی تصاویر نوستالژیک.

## ۳. ساختار فایل‌های پوسته (Theme Structure)

```
basate-nab/
├── style.css                  # اطلاعات پوسته، متغیرهای رنگی CSS
├── functions.php              # توابع ووکامرس، موتور سئو، اعداد فارسی و لود اسکریپت‌ها
├── header.php                 # نوار اعلان بالا، هدر چسبان، سرچ زنده و منوی کشویی موبایل
├── footer.php                 # فوتر ۴ ستونه، نوار اپلیکیشنی پایین موبایل و دکمه بازگشت به بالا
├── front-page.php             # صفحه نخست کامل با استوری‌ها، بنر هیرو، گرید کالاها و اینستاگرام
├── woocommerce.php            # کانتینر صفحات فروشگاه، آرشیو، سبد خرید و تسویه حساب
├── page.php                   # قالب صفحات ساده
├── single.php                 # قالب نوشته‌های وبلاگ
├── index.php                  # فید پیش‌فرض مقالات
├── deploy_sync.py             # اسکریپت استقرار خودکار و همگام‌سازی زنده با هاست وردپرس
├── assets/
│   ├── css/
│   │   └── main.css           # استایل‌های مدرن و ریسپانسیو RTL
│   └── js/
│       └── main.js            # جاوااسکریپت تعاملی، سرچ زنده، دراور موبایل و تایمر معکوس
├── README.md                  # راهنمای کامل پروژه
└── CHANGELOG.md               # گزارش تغییرات نسخه‌ها
```

## ۴. استقرار و همگام‌سازی زنده (Deployment Runbook)

هر زمان که تغییری در فایل‌های پوسته (PHP، CSS، JS) ایجاد کردید، با دستور زیر آن را مستقیماً بر روی هاست اعمال و فعال نمایید:

```powershell
cd C:\Users\Hamed\.gemini\antigravity\scratch\basate-nab
python deploy_sync.py
```

این اسکریپت:
1. پوشه را فشرده کرده و پکیج `basate-nab.zip` می‌سازد.
2. به پنل مدیریت وردپرس لاگین می‌کند.
3. فایل را آپلود کرده و جایگزین نسخه قبلی می‌نماید.
4. پوسته را فعال کرده و درستی عملکرد اندپوینت لایو را تایید می‌کند.
